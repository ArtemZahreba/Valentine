# Valentine Card Web Project ❤️

Цей проєкт я створив, коли почав вивчати PHP і захотів застосувати знання на практиці. Оскільки наближався День закоханих, мені здалося цікавою ідеєю зробити веб-сайт, який дозволяє надсилати віртуальні валентинки. 🎉

## 📌 Про проєкт

Проєкт реалізований у двох версіях:
- **PHP** версія – моя перша спроба працювати з мовою та її можливостями у веб-розробці.
- **Python Flask** версія – для розширення досвіду у веб-розробці з використанням іншого популярного фреймворку.

Цей веб-сайт дозволяє переглядати випадкові валентинки, які можна надіслати коханій людині. 💌

## 🔧 Технології

- **PHP** – серверна мова для генерації HTML-коду.
- **Python Flask** – мікрофреймворк для веб-розробки.
- **HTML, CSS** – для структури та стилізації сторінки.
- **JSON** – використовується для збереження текстів валентинок.

## 🚀 Як запустити

### 1. PHP версія
1. Завантажте файли проєкту.
2. Помістіть їх у серверне середовище (наприклад, XAMPP або OpenServer).
3. Відкрийте у браузері `http://localhost/`.


### 2. Запуск PHP-версії:

```sh
php -S localhost:8000
```

Після цього відкрийте в браузері:
```
http://localhost:8000
```

### Flask (Python) версія

#### 📌 Встановлення залежностей:
```sh
pip install -r requirements.txt
```

#### 🔥 Запуск сервера:
```sh
python main.py
```

## 🌍 Онлайн-версія

Ви можете переглянути веб-версію та поділитися валентинкою зі своєю другою половинкою або близькою людиною. 💖
